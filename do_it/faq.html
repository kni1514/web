Getting started

Common questions

What is do_it?

do_it is a Python terminal agent that uses your signed-in ChatGPT tab and local tools to work with files and shell commands.

How do I install it?

Clone the GitHub repository, install packages with python -m pip install -r requirements.txt, load the ext folder as an unpacked Chrome or Edge extension, then run python do_it.py.

What do I need?

Git, Python 3.10 or newer, Chrome or Edge, and an active ChatGPT sign-in. No separate API key is required.

Which devices can run do_it?

The same source setup works on Windows, macOS, Linux, and WSL where Python and Git are available. The browser extension currently needs a desktop Chrome or Edge browser.

Do I need to start the local server?

No. Running python do_it.py starts the local bridge automatically and closes it when do_it exits.

How do I update?

From the cloned repository, run git pull. If dependencies changed, run python -m pip install -r requirements.txt again.

ChatGPT is not responding. What should I check?

Confirm that Chrome or Edge is open, you are signed in to ChatGPT, the do_it extension is enabled, and the extension was loaded from the repository's ext folder.

Need more help?

Open an issue in the do_it repository.
