Quick setup

Requirements: Git, Python 3.10 or newer, and Chrome or Edge with a ChatGPT account.

git clone https://github.com/kni1514/do_it.git
cd do_it
python -m pip install -r requirements.txt

On Windows, use py instead of python if needed.

Connect the browser

  1. Sign in to ChatGPT in Chrome or Edge.
  2. Open chrome://extensions or edge://extensions.
  3. Enable Developer mode, choose Load unpacked, and select the cloned repository's ext folder.
  4. Keep the ChatGPT tab open while you use do_it.

Run do_it

Start an interactive session from the repository folder:

python do_it.py

Or pass a single prompt:

python do_it.py "list files in this project"

The local bridge starts with do_it and closes when the process exits. Enter help for commands or exit to quit.

Agent tools

do_it can read, write, edit, append, move, copy, and delete files; list folders; search files and the web; inspect file details; update JSON; and run shell commands.

How the ChatGPT connection works

The extension passes prompts and replies between do_it and your signed-in ChatGPT tab through a local server on your device. The local server starts automatically. When a task uses file or shell tools, relevant results are included in the ChatGPT conversation. Do not ask the agent to handle secrets you do not want sent to ChatGPT.
