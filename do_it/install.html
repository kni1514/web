Getting started

Set up do_it

One source checkout works across Windows, macOS, Linux, and WSL.

Before you begin

What you need

A computer with Python and Git, plus Chrome or Edge signed in to ChatGPT.

Python 3.10+

Install Python 3.10 or newer and make sure python is available in your terminal. On Windows, py can be used in its place.

Git

Git is used to clone and update the source repository.

Chrome or Edge

The browser extension connects do_it to your signed-in ChatGPT tab.

Install

Clone, configure, run

Follow these steps from any supported desktop operating system.

1. Clone the repository

Open Terminal, PowerShell, or Command Prompt and run:

git clone https://github.com/kni1514/do_it.git
cd do_it

2. Install Python packages

Run this from the do_it folder:

python -m pip install -r requirements.txt

On Windows, use py -m pip install -r requirements.txt if the python command is unavailable.

3. Load the browser extension

Sign in to ChatGPT in Chrome or Edge. Open chrome://extensions or edge://extensions, turn on Developer mode, choose Load unpacked, and select the repository's ext folder.

4. Start do_it

Keep the signed-in ChatGPT tab open. In a terminal at the repository folder, run:

python do_it.py

On Windows, use py do_it.py if needed. The local bridge starts automatically and closes when do_it exits.

Daily use

Start a chat or run one prompt

Interactive chat

python do_it.py

Type a request at the do_it > prompt. Enter exit to close the session.

Single prompt

python do_it.py "list files in this project"

Run one request and return to your terminal.

Update

git pull
python -m pip install -r requirements.txt

Run these commands from the cloned repository.

ChatGPT browser connection

Keep Chrome or Edge open with ChatGPT signed in and the do_it extension enabled. No separate API key or manual server start is needed.
