Clone from GitHub

do_it is distributed as source code. Git and Python 3.10 or newer are required.

1. Clone the repository

git clone https://github.com/kni1514/do_it.git
cd do_it

2. Install dependencies

python -m pip install -r requirements.txt

3. Set up ChatGPT

Sign in to ChatGPT in Chrome or Edge. Open the browser's extensions page, enable Developer mode, choose Load unpacked, and select the ext folder inside the cloned do_it directory.

4. Start do_it

python do_it.py

do_it starts its local bridge while it runs and closes that bridge when you exit.
